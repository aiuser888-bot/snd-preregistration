**已完成並有輸出可查：** `a.py`、`fc.py`、`sim.py`、`chk.py`、`r2.py`、`r3.py`（部分無效）、`r4.py`、`r5.py`、`r6.py`；V2.0.01；V2.0.02。
**沒有執行：** 規範 §7 的完整前置驗收（\(B\ge2\times10^4\)、\(K\in\{50,200,1000\}\)、多個 \(\phi\)、GPU 吞吐量實測）。所有模擬都是先導規模（\(R=1500\)–4000）。
**我之前說錯或無效的地方：**
1. 比對 V1.0.07 時我說「一維 Rice 下約 89% 排除機率」。實際數值：\(N=1.15\times10^{10}\)（\(T=3.791\)）時 FC–Rice 為 **0.871**（模擬 0.875），圓盤式為 0.595。
2. `a.py` 的 "rice" 列算的是單邊 \(\nu_{\rm up}\)（非 FC 排序），數字（\(T=3.227\)）不應與 FC 版（\(T=3.533\)）混用。FC 版為準。
3. `r2.py` 的位置—角度檢定我用了 Gamma(\(L-1\)) 零分佈，KS 檢定 p≈0，參數寫錯。實測零分佈均值 99.95、標準差 10.09（\(L=100\)），即約 Gamma(\(L\))。
4. `r2.py` 與 `r3.py` 的「偏差 × 漂移」測試**無效**（洩漏均勻或強度太小，三種處理都約 0.045–0.057，不能說明任何事）。有效版本是 `r4.py`。
5. V2.0.01 §5.1 的 \(\nu\le13\) 網格在 \(x>11\) 失真（\(u(14)-14=-1.0\)），V2.0.02 已更正。

## 4. 尚未解決（依對正確性的影響排序）

1. **序列相關 \(x\) 下的 H₁ 與覆蓋率**：H₁ 目前只定義在逐單位獨立抽樣；相關下 \(\mathrm E[U]\) 與 UCB 覆蓋率未知。

3. **重現成功判定（#13）**：需作者選定修正方式。
4. **§7 全套驗收未以規範規模執行**，以及 Rice 近似在大 \(K\)、其他 \(f\) 分佈下的覆蓋率。
5. **\(\mathbb E[\widehat f^2]\ge0.25\) 的可達性**取決於探索集的 \(\widehat f\)；沒有探索集資料就無法判斷。
6. 置換檢定的 GPU 預算實測。
