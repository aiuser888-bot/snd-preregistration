## V2.0.06→V2.0.07 逐項更正（潤稿時發現的矛盾）
1. **【數學錯誤】引理 2(iv) 的 ν_eff 與覆蓋門檻**：V2.0.04–V2.0.06 寫 ν_eff=ν/√κ，同時覆蓋事件門檻用 x_min(ν)，但 ν 在 §5 定義為 r/σ̂（實際 V）。EU=rV/κ ⇒ x̂ 的非中心參數 = ν/κ（ν=r/σ̂）；若以 iid σ₀ 定義 ν₀，則門檻為 x_min(ν₀√κ)。舊式在 κ≈1 時幾乎無差，但在 κ 小時系統性低估覆蓋率。修正後：28 格（r17 15＋r18 6＋r20 4＋r19 3）平均 z 由 +0.62 → −0.05，|z|>2 由 7 → 4，max|z| 2.79 → 2.94（r17 ρ=0.9,ν=3，模擬 0.9780 對預測 0.9858，低於 Bonferroni 臨界 3.12）。無任何覆蓋率低於名目。
2. 引理 2(i) 原寫「一階近似、略去 O(r²)」→ 實為邊際傾斜下精確（僅欄中心化 O(1/K)）。
3. 引理 2(iii) 原因由「α_b 獨立」→「均勻排列下各位置角度均值為零」；引理 1 註明二階矩不需 α_b 均勻，α_b 均勻只用於分佈旋轉不變。
4. 引理 2(ii) 原寫「未做兩向中心化的 V」→ 實為列中心化 V_b。
5. 設計原則句原寫「所有推論只依賴區塊隨機化設計」→ 與 UCB 需 A3/A3′＋CLT 矛盾，已分開陳述。
6. 「H₀ 下 Λ 的分佈不受漂移影響」→ 改為「不影響檢定有效性」（V 隨 x 變）。
