# SND 稽核 V2.0.10（接續 V2.0.09 稽核；V2.0.09 與舊檔保留）

## 輸入
作者詢問 V2.0.09 §12.5 兩個選項（事後取得種子／事前承諾）的影響，並追問「B 破壞了初始的實驗動機吧？」，隨後要求生成新版本並遞迴自查。

## 評估
1. **B 破壞動機：屬實。** 依據是規範自己的 §12.5（「與『θ 在 x 之後才決定』的實驗動機衝突」）與 README／交接文件對實驗的描述（x 先封存，θ 之後才指派）。我只依這些文字判斷動機，沒有看過最初的討論文件。
2. **A 不是免費的。** A 把「θ→x 的古典路徑」交給因果順序，但換來兩條要靠工程防的路徑：環境→QRNG→θ，與操作者的抽取時機／重抽自由度。V2.0.10 對這兩條都給了明文程序與可計算的後果（引理 5）。
3. **一次性 vs 逐批：** §2 的全域中心化本來就要求全部 x 先凍結，所以一次性取得與規範字面順序一致；逐批取得會重現 C 類結構。
4. **範圍限制（未解）：** 若 θ 必須在採集期間實體施加（§0「θ 零點」所指的硬體參考系若即此意），整個 12.5.1 不適用（12.5.5）。規範文字沒有說清楚，**需要作者確認**。

## V2.0.09→V2.0.10 逐項
1. **【決定】** §12.5 定案選項 A：全部設備、全部區塊的 x 封存並凍結（T_F，雜湊 H_F 取得外部時間戳）之後，每台設備一次性取得 QRNG 種子；總抽取至多 3 次（健康檢測或 θ-only 檢查失敗才重抽），全部入稽核鏈；操作者無權；不得追加資料或重複分析。取捨紀錄（B、逐批、信標）寫入 12.5.2。
2. **【新增·數學】引理 5（種子通道）：** θ 的唯一隨機輸入是種子 ⇒ 任何洩漏來源都經由 P(S|G)。(a) 設計矩 E|U|²=2V、E U²=0（精確）；(b) β≤√D（D＝χ² 散度；Cauchy–Schwarz，取等號可達）；(c) 型一錯誤≤0.05+½√D（不需 CLT）；(d) 取最有利的 k 次抽取：1−0.95^k；(d′) θ-only 檢查失敗而重抽：≤0.05/(1−f)；(e) E_h D=(2^λ−1)CP≤2^{λ−H₂}（GF(2) 線性雜湊取等號）；(f) 註冊要求 H₂≥λ+32 ⇒ D≤2^{−32}，4 台 9.3×10⁻¹⁰、β≤3.1×10⁻⁵、型一錯誤至多超出 0.05 約 1.5×10⁻⁵。
3. **【改寫】** §0 A1、§1、§2、§3.1–3.3、§4、§10、§11、§12 intro／12.1／12.2／12.4／12.6／12.7 的時序字句全部以 T_F 為界；§12.4 的殘餘假設由「假設 β*」改寫為 E1（資料可檢：公開種子後逐位元重算 θ）＋E2（物理假設：條件於 G 的原始熵≥λ+32）＋理想化 (I)(H)；β* 改為對 E2 部分失效的容忍度（D≤β*²）。重現實驗室獨立執行 12.5.1。
4. **【程式】** `design.py`：`seed_material`、`MIN_RAW_BYTES=64`（原下限 128 位元不足以使引理 5 的界有意義）；`leak.py` 新增 8 個函式；測試 11→18 項；`check_numbers.py` 28→40 項；`legacy/r23.py`（原型驗證，已由測試取代）。

## 自查紀錄（三輪）
第 1 輪（寫完後逐項質疑）
- **【數學】** 初步推導只得 β≤√(2D)。原型數值（`legacy/r23.py`）顯示單一方向傾斜的比值只有 0.707 → 改用單位向量投影，得緊的 β≤√D；取等號的傾斜（ε=0.05/0.2/0.4）比值 1.000000000。
- **【邏輯】** 引理 5(c) 草稿把覆蓋事件也寫成 TV 界；H₁ 下 x 依賴 θ，條件化會循環 → 限定為 H₀ 的陳述，覆蓋率改用引理 3(c) 的一階可加近似並明寫「近似，不是定理」。
- **【缺口】** T_F 之後追加資料或換種子重跑 = 多次檢定 → 明文禁止並連到 (d)。
- **【缺口】** §12.1 對 G 的描述改為明說「除種子外的一切」。
第 2 輪（程序走一遍：「如果它在 0.1% 的情況下失敗呢？」）
- **【缺口】** §3.2 均勻性檢定偶然失敗（FWER 10⁻³）時，原規則「分析無效」會報廢整個實驗 → 改為重抽（計入 3 次上限）；因檢查只用 θ，第一個通過者的律為 P₀(·|通過)，型一錯誤≤0.05/(1−f)。設計檢查（機率 0）失敗仍視為實作瑕疵、不重抽。
- **【缺口】** 共用同一 QRNG 時乘積式 ∏(1+D_d)−1 不成立 → 改對串接輸出要求熵≥n·λ+32。
- **【缺口】** θ 的雜湊須入稽核鏈，E1 才有比對對象。
- **【措辭】** 「任意傾斜皆 β≤√D」把隨機測試誤寫成一般陳述 → 改為「隨機傾斜」，並在 (g)2 註明只是例子；(b) 的取等號條件補「在 ℓ≥0 允許的範圍內」。
第 3 輪（整份對照）
- **【符號】** 金鑰長度 m 與 §4 的重抽序號 m、統計量 U（U_m）重名 → 金鑰長度改 λ、均勻律改 Unif_λ，重抽序號回到 m；程式參數同步（`lam`）。
- **【邏輯】** 舊 §12.5 第一項控制寫「預註冊種子」，預設了選項 B，與「未決定」矛盾 → 隨定案改寫。
- **【一致性】** §8.3 與引理 3 的逐單位傾斜 q 模型在新程序下對應「E1 被破壞」，已於 12.5.3(g)3 說明。
- **【程式事故】** 編輯 `__init__.py` 時 `open(…,'w')` 先於 `read()` 把檔案清空 → 立即從已驗證的 V2.0.09 套件還原再改版號；順手更正過時的 docstring「protocol v15」。
- **【可驗證性】** 刪除 `check_numbers.py` 中一條恆真的檢查（β*=0.25 ⇒ √D=0.25）；`reproduce_all.py` 在臨時副本以 60 次重複跑通（種子材料長度規則改變後無例外；僅煙霧測試，不取代正式的 1000 次）。
