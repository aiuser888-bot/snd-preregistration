# SND 稽核 V2.0.08（接續 V2.0.07 稽核；V2.0.07 與舊檔保留）

## 背景
輸入：外部 AI 對 C 類偏差的建議——「把 C 類從無法處理的反例，轉成可量化的殘餘風險：(1) 實作隔離與時間因果鏈；(2) 用環境代理變數給出可驗證的 γ 上界；(3) 公開 α(γ) 曲線」，並問這是否能優化當前版本。結論：**部分可以**。(1) 是程序性控制，無數值保證；(3) 可行，但需先把「γ」與「α」定義成可計算且不與既有符號衝突的量；(2) 以原樣實作會是空的（見下），改成環境投影檢定後才可驗證。**無條件精確水準 0.05 仍不能恢復。**

## V2.0.07→V2.0.08 逐項（含自查撤回的設計）
1. **【定義】** 正規化偏差 β=|E[U|G]|/√V；均方根傾斜 γ；對齊度 ω。引理 3(a) 證明 β=ω√(2(L−1)/L)·√N·γ≤√(2N)γ（Cauchy–Schwarz；`test_leak_cauchy_schwarz_and_exact_bias` 驗證等號條件）。
2. **【評估：γ 上界不能直接由資料給】** 只用 θ 與環境變數時，偵測門檻比 β=0.25 所需的 γ≈1.7×10⁻⁶（ω=1）大約 140 倍；而 U 本身對 B 的解析度只有 1σ。改為引理 4 的 U_mon：把 θ 投影到環境類別上與 f̃ 的類別和相乘，解析度 s_mon≈η√V（η 為類別對 f̃ 能量的解釋比例）。**能證明的上界下限是 2.448η**，所以它是「對已監測通道的精確檢定與粗略上界」，不是 γ 的緊上界。
3. **【符號衝突】** 原建議的 α(γ) 與 α_b（區塊旋轉）及檢定水準 α 衝突 → e_I(β)。§8.3 原用的 δ（位置第一諧波偏差）與正規化偏差混淆 → §8.3 改 q，偏差用 β。
4. **【設計缺陷，自查撤回】** 原擬以 β_mon^ub≤0.5 納入閘門：β_mon^ub≥2.448η（η≈0.25 時≥0.61），永遠不可達（模擬 `r21c_part1_perfect.out` 的 ub 欄為 0.000 即此故）→ 只報告，不進閘門。
5. **【數學錯誤，自查修正】** `coverage_min_over_nu` 初版 ν 掃到 20，超出 FC 表有效範圍（x̂≤18 ⇔ ν≤15），β=0 出現假最小值 0.955（Rice 最小為 0.9709）→ 限 ν∈[0,15]，格點 0.005，回到 0.9707。
6. **【邏輯，自查】** (a) 類別若用 x，H₁ 下 x 依賴 θ，可交換性失效 → 建議只用環境紀錄；(b) 環境紀錄若取自角度產生之後，可能是 θ 的後果 → 規定只用角度產生前的紀錄；(c) 引理 3(a)(b) 只在 H₀ 下陳述，(c) 以可加近似處理 H₁。
7. **【數字，自查】** 閘門的代價：誤報 0.05 → 淨排除機率 0.850→0.807–0.833，淨功效 0.923→0.878；§6 原句「V_target 含 10% 餘裕」在加閘門後不成立（約 2%），已改寫並保留 V_target 不變（是否提高屬作者決定）；§7(C) 驗收改為含閘門的淨值；§10 重現成功機率乘 0.95 並加入條件 (iii)（乘 0.95 為近似，未做全流程模擬）。
