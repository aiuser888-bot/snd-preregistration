## 二、設計方向的轉折（機關期 → 轉向驗證期）
以設計保證取代機制：
- 區塊內隨機排列 → 隨機化檢定精確（取代去對齊 bootstrap 與次序統計量）。
- 解析 FC–Rice 一維界 → 取代網格、二維投影與次序統計量。
- V 由資料直接計算、置換只累積 U → 取代重要性加權、配分函數、ESS、MCSE。
- 跨設備相關降為診斷；M_perm=1999；停止規則只依 x。

## 三、被推翻或更正的主張（累計）
- 「Rice 相對圓盤降 N 到 1/2.7」→ 實際約 1.25 倍（V1.0.03 審閱）。
- 「H₀ 下 r̂ 嚴格 Rice」→ H₀ 為 Rayleigh、漸近（V1.0.04）。
- 「區塊內不放回使 U 變異數較小」→ 去平均後略大 L/(L−1)（V1.0.06）。
- 2D 密度 UCB／自適應 N → 一維 FC–Rice UCB 與固定 V_target 停止。
- T_pos 的 Gamma(L−1) 虛無分佈錯誤；經驗均值≈L、標準差≈√L。
- FC 表 V2.0.01 網格造成 x>11 失真，V2.0.02 修正。
- 「89% 排除機率」→ 0.871。
- V2.0.02 的「未中心化 0.142」來自 r4 的 bug；V2.0.03 起改用 r8。
- C 類偏差（區塊變動洩漏×區塊特有漂移）任何中心化都無法消除，型一錯誤約 0.15，列為反例。
- T_pos 偵測門檻約 2.4×10⁻⁴，遠大於有害門檻約 5.7×10⁻⁶，不能用來證明無害。
- r13：一次崩潰（浮點種子）＋預測式邏輯錯誤＋舊 AR(1) 起始錯；r17 變數被覆寫，全部修正重跑。
- 引理 2(iv)：V2.0.04–V2.0.06 的 ν_eff=ν/√κ 與覆蓋門檻有誤，V2.0.07 更正為 ν/κ。
- V2.0.08：C 類由「無法處理的反例」改為「後果可量化、已監測部分可檢出並設閘門、未監測殘餘只能假設」；自查中撤回兩個設計（β_mon 上界納入閘門、ν 掃描超出表格範圍）。
- V2.0.09：閘門使 V_target 的淨餘裕由 10% 降到約 2%，故 V_target 1.375×10⁹ → 1.5×10⁹，連動數字重算；同時更正一處把不同 T 的功效拿來比較的舊錯位。
- V2.0.10：§12.5 定案選項 A（全部 x 凍結後才一次性取得種子；選項 B 因使 θ 先於 x、與實驗動機衝突而不採用）；新增引理 5：θ 的唯一隨機輸入是種子 ⇒ β≤√D、型一錯誤≤0.05+½√D（D＝種子條件律對均勻的 χ² 散度），未監測通道的殘餘假設改寫為 E1（資料可檢）＋E2（物理假設）；自查修正：β≤√(2D) 初稿→緊的 √D、覆蓋率的 TV 論證限 H₀、補上重抽規則與禁止追加資料、種子材料下限 128→512 位元、一次清空 `__init__.py` 的程式事故。

## 四、目前主張的證據等級（V2.0.10）
- **已證明**：引理 1；隨機化檢定精確性（給定 A1、x-only 前處理與停止規則）；引理 2(ii)(iii)(v)(vi 於 H₀)；引理 3(a)（B=Σf̃q 與 β≤√(2N)γ）；引理 4(a)(b)（U_mon 的 p 值精確、期望為 B_mon）；引理 5(a)（設計矩）與 5(b)–(e)（β≤√D、型一錯誤≤0.05+½√D、best-of-k、重抽、雜湊—熵恆等式；後者在理想化 (I)(H) 下為定理，並以精確列舉驗證其代數）。**未證明且不主張**：無條件精確水準 0.05（A1 不可由資料證明）。
- **數值支持**：FC 表接受質量 0.9500–0.9505；Rice 覆蓋率最小 0.9709；相位獨立（未偵測到差異）；κ 封閉式；序列相關下覆蓋率（28 格，最低 Wilson 下界 0.957）；一種條件傾斜模型；跨區塊共享成分（保守）；L=10⁴ 單區塊分數近高斯；e_I(β) 與偏差下覆蓋率（縮小規模各 8 格）；U_mon 解析度公式 η；閘門複合型一錯誤（高斯模型解析＋模擬抽樣點）。
- **未驗證／未解**：E2（條件於 G 的原始熵，物理假設）與理想化 (I)(H) 對真實 QRNG／Philox／SHA-256 的適用性、§12.5.1 程序的實作與熵源特性化、θ 是否須在採集期間實體施加（§12.5.5）、一般條件傾斜、實際規模下的引理 3(b)(c) 與 η、E[f̂²]≥0.25（待資料）、GPU 實測（含 U_mon 額外成本）、θ 零點對齊（硬體）、類別分割的探索集建構流程。
